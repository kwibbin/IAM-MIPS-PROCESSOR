branch prediction test. paste the array body into instruction_mem.vhd.

the bht starts at weak not-taken (01) and the btb starts empty, so the first
execution of any branch is a btb miss and is predicted not taken. a branch has
to resolve taken at least once before it can ever be predicted taken, which is
why a single branch executed a single time proves nothing. the loop below runs
its branch 3 times to walk every predictor state:

  pass 1  btb miss     -> predict nt, resolves taken     -> mispredict
  pass 2  btb hit, 10  -> predict t,  resolves taken     -> correct, no bubble
  pass 3  btb hit, 11  -> predict t,  resolves not taken -> mispredict, recover to pc + 4

the beq at 28 then adds a cold forward branch that is actually taken, and its
fall through at 32 is unreachable by any correct execution, so it doubles as a
flush canary.

expected end state: $1 = 0, $2 = 3, $3 = 7, $4 = 0, $5 = 5
a non-zero $4 means a mispredicted instruction was allowed to retire.
